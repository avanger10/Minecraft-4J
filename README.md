# Minecraft-4J
Minecraft Wii U Edition Android

Un port de Minecraft: Wii U Edition para dispositivos Android.

Este proyecto adapta LCEReborn para llevar la experiencia de Minecraft Legacy Console Edition (Wii U) a dispositivos Android.

🎮 Características

- Port de Minecraft Wii U Edition para Android.
- Adaptación de código nativo.
- Compatibilidad con arquitectura ARM64-v8a.
- Integración de SDL3.
- Controles adaptados para Android.
- Proyecto desarrollado y compilado desde Termux.

📱 Compatibilidad

- Plataforma: Android.
- Arquitectura: ARM64-v8a.
- Dispositivo de desarrollo: Redmi Note 14 Pro+ 5G.

📦 Instalación

Descarga el APK desde la sección Releases de este repositorio e instálalo en tu dispositivo compatible.
